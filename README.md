# trabalhomata60
Entregáveis para a Entrega 1 (MIDB) do Trabalho de Banco de Dados

Os arquivos incluem:
1. criar_banco.sql - Arquivo para criação do banco de dados no pgAdmin
2. popular_banco.sql - Arquivo para popular o banco/preencher as tabelas, sendo 3 delas com 5000 registros.
3. gerar_populacao_banco.py - Arquivo com o script utilizado em Python para gerar os comandos SQL responsáveis por inserir os 5000 registros em 3 tabelas.
4. mapeamento_entidade_relacionamento.png - Arquivo com o mapeamento MER.
